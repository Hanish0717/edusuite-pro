# Routing Standards & Guide

This document establishes our nested TanStack Router guidelines.

## Guidelines

- **File-based Routing**: Place parent layout files in `src/routes/module-name.tsx`.
- **Sub-pages Configuration**: Sub-pages map to `src/routes/module-name.sub-page.tsx`.
- **Navigation Configuration**: Define routes in `src/shared/config/navigation.config.ts` to automatically populate sub-sidebars.
