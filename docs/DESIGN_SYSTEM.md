# Design System & Premium UI Guidelines

This document maps color styles, typography scales, layout spacing, shadows, and animations to ensure a pixel-perfect, premium look across all institutional dashboards.

## Theme & Palettes

- **Primary Accent**: Monochromatic Royal Blue (`#1d4ed8`) as the dominant color.
- **Glassmorphism**: Border opacity overlays, blurred backdrops, and card containers.
- **Micro-Animations**: Hover animations on action buttons and list items.

## Global Tokens

Re-export and reference global tokens under `src/shared/design-system/` to avoid manual color/spacing declarations in raw code.
